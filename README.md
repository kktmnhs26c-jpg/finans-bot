# Telegram-бот для учёта доходов и расходов

Готовый бот: пишете ему обычным текстом, а он сам определяет сумму, тип операции и категорию.

## Примеры

- `кофе 350`
- `продукты 1850`
- `такси 420`
- `игры 1500`
- `путешествие 25000`
- `зарплата 85000`
- `получил 12000 за работу`
- `-500 бензин`
- `+50000 зарплата`

## Что умеет

- автоматически отличает доход от расхода;
- автоматически определяет категорию;
- считает доходы, расходы и баланс;
- отчёты за день, неделю, месяц и всё время;
- последние 10 операций;
- удаление последней ошибочной записи;
- выгрузка всех операций в CSV/Excel;
- можно ограничить доступ только своим Telegram ID.

## Шаг 1. Создать самого Telegram-бота

1. В Telegram откройте `@BotFather`.
2. Отправьте `/newbot`.
3. Укажите имя бота.
4. Укажите username, который заканчивается на `bot`.
5. BotFather пришлёт токен вида `123456:ABC...`.
6. Никому не публикуйте этот токен и не вставляйте его в код/GitHub.

## Шаг 2. Загрузить файлы в GitHub

Создайте **Private** репозиторий, например `finance-bot`, и загрузите туда:

- `finance_bot.py`
- `requirements.txt`
- `render.yaml`

`.env.example` можно загрузить — в нём нет настоящего токена.

## Шаг 3. Запустить на Render

1. Откройте Render.
2. Подключите GitHub.
3. Создайте `New` → `Web Service`.
4. Выберите репозиторий `finance-bot`.
5. Build Command: `pip install -r requirements.txt`
6. Start Command: `python finance_bot.py`
7. В Environment Variables добавьте:
   - `BOT_TOKEN` = токен от BotFather
8. Deploy.

После запуска напишите боту `/start`.

## Шаг 4. Закрыть бота только для себя

Сначала оставьте `ALLOWED_USER_IDS` пустым и запустите бота.

1. Напишите боту `/id`.
2. Он покажет ваш Telegram ID.
3. В Render добавьте переменную:
   - `ALLOWED_USER_IDS` = ваш ID
4. Сделайте redeploy.

Теперь посторонние не смогут пользоваться ботом.

## Важный момент про базу на Render

Сейчас бот хранит данные в SQLite-файле `finance.db`.

На бесплатном Render локальный диск может очищаться при пересборке/перезапуске. Для постоянного хранения лучше:
- подключить Persistent Disk на Render, либо
- перейти на PostgreSQL/Supabase.

Для первого запуска и проверки текущая версия подходит.

## Локальный запуск

```bash
pip install -r requirements.txt
export BOT_TOKEN="ваш_токен"
python finance_bot.py
```

На Windows PowerShell:

```powershell
$env:BOT_TOKEN="ваш_токен"
python finance_bot.py
```
