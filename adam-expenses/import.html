Перенос расходов

Импортируйте записи из старого сайта в Расходы — Адам на этом устройстве. Файл обрабатывается в вашем браузере и никуда не отправляется.

1. На старом сайтеОткройте список расходов и скачайте Экспорт CSV. Если есть фильтр дат, выберите весь период — не только текущий месяц.
2. Выберите скачанный CSV
3. Проверьте данные

Существующие записи сохраняются. Повторно загруженные одинаковые строки не добавляются.

Открыть учёт расходов

Важно: новые данные сохраняются только в этом браузере и не синхронизируются автоматически с другим устройством. После импорта нажмите «Резервная копия» в основном приложении.
